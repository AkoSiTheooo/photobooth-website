# Sounds

Drop these two files here and the booth starts using them. While a file is missing the
booth stays silent and the mute control stays hidden, so there is never a dead button.

| File                 | When it plays                        |
| -------------------- | ------------------------------------ |
| `countdown-tick.mp3` | Once per second during the countdown |
| `shutter.mp3`        | At the moment a photo is taken       |

Any mp3 works; short is better (under a second for the tick). Sounds respect the mute
button, and they keep working for visitors who asked for reduced motion.
